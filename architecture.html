The overview

The tools, and how a request reaches a model. The home page shows the same diagram, from one file, website/_overview.qmd.

Where everything sits

  • Everything on the Spark listens on 127.0.0.1, except SSH and tailscale serve’s port 443. The tailnet’s rules let my own devices reach the Spark on those two ports only, and ufw allows SSH alone from the LAN.
  • Three accounts on the Spark. Mine, the admin; spark, which runs llama-swap, the engines and the brake; and agent, for coding agents in tmux, with no sudo, no docker and keys of its own. Root runs the web services from its own copies of their units.
  • Claude never uses the Spark’s models. Claude Code and Claude Desktop talk straight to Anthropic, wherever they run; Orca only starts them. The Spark is a separate mode.

Reaching the Spark

pi on the Mac reaches llama-swap only while make tunnel runs, since nothing on the Spark listens beyond 127.0.0.1 but SSH. The web UI needs Tailscale: on another tailnet, over WireGuard, the LAN alias still carries SSH and so pi’s tunnel, but the web UI waits. agent’s pi needs no tunnel. opencode and Hermes on the Mac go through the same tunnel, with the same key (since 2026-10-14, make clients). From Phase 3, apps reach the models through LiteLLM, each with a key of its own. From Phase 6, family and friends reach the web UI and LiteLLM over a shared Tailscale node that shows them only the Spark, and guests at an event reach LiteLLM and a guest web UI of their own, on the venue’s network only.

Loading a model

A model loads only if it fits: nothing is evicted to make room, and nothing is swapped for a smaller model. Free memory is the smaller of MemAvailable and what the GPU can allocate, and the reserve stays free, because overcommitting a GB10 can freeze it without an out-of-memory kill.

Apps and speech (Phase 3, planned)

Today the web UI and pi reach llama-swap directly with llama-swap’s own keys. From Phase 3, my own pipelines and homelab apps come in through LiteLLM instead, each with a key of its own; it never logs what they send.
